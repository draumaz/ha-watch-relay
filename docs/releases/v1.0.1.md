# WristBridge 1.0.1

**Much smaller downloads.** No functional changes.

Release builds are now shrunk with R8 (code and resource shrinking), which strips unused library code and resources that 1.0.0 shipped in full.

| APK | 1.0.0 | 1.0.1 |
|---|---|---|
| Phone | 15.8 MB | ~2.0 MB |
| Watch | 50.6 MB | ~2.6 MB |

## Upgrading

Install both the **phone APK** and the **watch APK** attached below over your existing 1.0.0 install. Your settings, token and tile configuration are kept. As before, both APKs are signed with the same key, which the Wearable Data Layer requires to pair them.
